| ----------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| This flake: the Nix around the release, the `update-version` and `update-branches` scripts, these documents | [MIT](LICENSE.md)                                                                                                                                                                                                                                                                                                                               |
| [code-server](https://github.com/coder/code-server) at the release `pin.nix` selects                        | [MIT](https://github.com/coder/code-server/blob/v4.143.1/LICENSE), `Copyright (c) 2019 Coder Technologies Inc.`; the terms of everything inside the release are upstream's own record, in [`ThirdPartyNotices.txt`](https://github.com/coder/code-server/blob/v4.143.1/ThirdPartyNotices.txt) and the licence files beside each bundled package |
| `nodejs`, `bash` and the rest of the runtime closure                                                        | As the consumer's nixpkgs records each one in `meta.license`, where `free` and `redistributable` are separate properties                                                                                                                                                                                                                        |

The install phase copies the release tree verbatim with fixup disabled and nothing patched, so `LICENSE` and `ThirdPartyNotices.txt` travel inside `$out` to whoever the built output is served to; the pinned tarball is fetched only when a derivation is built, so evaluating or promoting this repository conveys nothing.
